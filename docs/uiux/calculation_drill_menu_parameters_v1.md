# 小学校1〜6年生 計算ドリル メニュー・固有設定一覧

> **設計方針**
>
> - メニュー名は「ユーザーが何を練習するか」が分かる粒度にする。
> - 同じ演算のバリエーション（繰り上がり、繰り下がり、同分母・異分母、帯分数など）は、可能な限り固有設定にする。
> - その学年・ドリルで選択肢が1つしかない設定は、設定UIにはせず「固定値」として表示する。
> - 「難易度（基礎 / 標準 / 発展）」はメニューに表示するラベルであり、ユーザー設定項目ではない。
> - 問題数、解答の有無など全ドリル共通の項目は、この表では扱わず「詳細設定」にまとめる。
> - 難易度は、その学年で初めて学習するときの相対的な位置づけ。

## メニュー統合による変更

元の61カテゴリのうち、分数の加減算については、UI上のメニューを以下のように統合する。

- 「簡単な同分母分数の足し算」「同分母分数の足し算」「帯分数を含む同分母分数の足し算」「異分母分数の足し算」「帯分数を含む異分母分数の足し算」
  → **分数の足し算**
- 同様の引き算カテゴリ
  → **分数の引き算**

学年によって利用可能なパラメータを段階的に開放する。

| 学年 | 分母 | 数の種類 |
|---|---|---|
| 小3 | 同分母（固定表示） | 分数（固定） |
| 小4 | 同分母（固定表示） | 分数 / 帯分数を含む / まぜる |
| 小5 | 同分母 / 異分母 / まぜる | 分数 / 帯分数を含む / まぜる |

## UI実装上のルール

1. **選択可能値が複数ある場合**
   - セグメントコントロール等で変更可能にする。

2. **値が1つに固定される場合**
   - 設定項目自体は表示する。
   - 選択可能な場合と同一形状のセグメントコントロールで表示しつつ、全選択肢を非活性（`disabled` / `aria-disabled`）にし、固定値を選択済み表示にする。
   - その設定が別の学年・ドリルで選択可能な場合（繰り上がり／繰り下がり＝なし・あり・まぜる、分母＝同分母・異分母・まぜる）は、その選択肢一式を非活性で並べる。選択可能な形が存在しない設定は、固定値1つだけの非活性ピルで表示する。
   - 例：小学3年生「分数の足し算」→ `分母：[同分母(選択)] [異分母] [まぜる]`（すべて非活性）

3. **固有設定がない場合**
   - 無理に設定欄を作らない。
   - タイトル・難易度・例題・詳細設定・生成ボタンだけで構成する。

4. **共通設定**
   - 問題数など、ドリル内容そのものを変えない設定は「詳細設定」にまとめる。
