# 100マス計算ジェネレーター

## 概要
このプロジェクトは、100マス計算の練習問題をPDF形式で自動生成するツールです。
足し算、引き算、掛け算のいずれかの形式で、指定した数の問題を作成できます。

## 特徴
*   足し算、引き算、掛け算の100マス計算問題を生成可能
*   生成する問題数を柔軟に指定可能
*   高品質なPDF形式で出力

## 使い方

### 1. Pythonスクリプト (`100masu.py`) の実行

`100masu.py`スクリプトは、100マス計算のTeXファイルを生成します。

```bash
python 100masu.py [-n <問題数>] [-o <出力ディレクトリ>] [-t <計算タイプ>]
```

#### オプション:
*   `-n`, `--number`: 生成する問題の数 (デフォルト: 10)
*   `-o`, `--output`: TeXファイルを出力するディレクトリ (デフォルト: `./`)
*   `-t`, `--type`: 計算のタイプを指定します。
    *   `add`: 足し算 (デフォルト)
    *   `sub`: 引き算
    *   `mul`: 掛け算

#### 例:
足し算の問題を5問生成し、`output`ディレクトリに出力する場合:
```bash
python 100masu.py -n 5 -o output -t add
```

### 2. シェルスクリプト (`factory.sh`) の実行

`factory.sh`スクリプトは、`100masu.py`を実行してTeXファイルを生成し、それを`platex`と`dvipdfmx`を使ってPDFに変換します。
生成されたPDFは`result.pdf`という名前で出力されます。

```bash
./factory.sh
```

#### 例:
```bash
./factory.sh
# これにより、10問の足し算の100マス計算問題が生成され、result.pdfとして出力されます。
```

## 動作環境
*   Python 3
*   LaTeX環境 (platex, dvipdfmx)
